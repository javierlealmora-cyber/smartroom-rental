## Variables de entorno necesarias para E2E completo

Añadir a `tests/e2e/.env.e2e`:
```
TEST_MANAGER_EMAIL=...
TEST_MANAGER_PASSWORD=...
TEST_LODGER_EMAIL=...
TEST_LODGER_PASSWORD=...
TEST_ACC_ID=...        # UUID de alojamiento con inquilinos activos
TEST_BILL_ID=...       # UUID de factura en estado 'pending' para ENE-09
```
